Input File Requirements & Instructions

1. Site Data CSV

Upload a CSV containing site locations and sector information.

Required fields

  • USID — unique site/node identifier
  • LATITUDE — numeric latitude
  • LONGITUDE — numeric longitude
  • AZIMUTH — sector direction in degrees

Recommended fields

  • ENODEB_New — readable site/node name
  • CELL — cell or sector name

Site names and cell names are optional. USID, coordinates and azimuth are required by the current processing logic.

2. Neighbour SQL Table

Upload the table containing configured neighbour relations.

Required fields

  • USID — source site identifier
  • ClusterUSID — neighbour site identifier

Optional fields

  • ClusterName — cluster name
  • HO ATT — handover attempts/metric
  • % Sharing — sharing percentage

Accepted formats: XLSX, XLS or CSV. Optional columns are used when present.

Before clicking Go

  1. Check that both files contain the correct headers and data.
  2. Ensure site IDs match between the two files.
  3. Check that coordinates and azimuths contain valid numeric values.
  4. Upload both files, enter your SIGNUM ID and click Go.

Header aliases are accepted only when configured in the tool. Missing required fields or ambiguous duplicate columns must be corrected.
